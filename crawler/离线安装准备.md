# 离线安装准备说明

## 📋 问题
内网环境无法访问外网，`pip install` 和 `playwright install` 无法正常运行。

## ✅ 解决方案：两步流程

---

## 第一步：在外网电脑上准备安装包

### 1. 准备 Python 包

打开命令行，进入 crawler 文件夹：

```bash
# 创建离线包目录
mkdir offline_packages

# 下载所有 Python 依赖到本地
pip download -r requirements.txt -d ./offline_packages
```

这一步会下载 `playwright`、`python-dotenv` 以及它们的所有依赖包到 `offline_packages` 文件夹。

### 2. 准备 Playwright 浏览器

#### 方法 A：使用 Playwright 内置的下载命令（推荐）

```bash
# 先安装 playwright
pip install playwright

# 下载浏览器（会提示浏览器安装位置）
playwright install chromium --dry-run
# 注意：--dry-run 只是查看下载位置，实际执行去掉 --dry-run
```

#### 方法 B：手动下载浏览器包

根据你的系统，从以下地址下载：

| 系统 | 下载链接 |
|------|---------|
| Windows x64 | https://playwright.azureedge.net/builds/chromium/1422/chromium-win64.zip |
| Linux x64 | https://playwright.azureedge.net/builds/chromium/1422/chromium-linux.zip |
| Mac x64 | https://playwright.azureedge.net/builds/chromium/1422/chromium-mac.zip |
| Mac ARM64 | https://playwright.azureedge.net/builds/chromium/1422/chromium-mac-arm64.zip |

**注意**：版本号可能需要调整，建议先在外网运行一次 `playwright install chromium`，然后查看浏览器安装目录：

- Windows: `%USERPROFILE%\AppData\Local\ms-playwright`
- Linux/Mac: `~/.cache/ms-playwright`

找到对应的文件夹，复制到 `offline_browsers` 目录下。

### 3. 整理文件结构

在外网准备完成后，文件结构应该是：

```
crawler/
├── offline_packages/        # Python 包（.whl, .tar.gz 文件）
│   ├── playwright-1.40.0-...
│   ├── python-dotenv-1.0.0-...
│   └── ...
├── offline_browsers/        # 浏览器文件
│   └── chromium-1422/
│       └── ...
├── config.py
├── browser.py
├── crawler.py
├── analyze.py
├── requirements.txt
├── .env.example
└── ...
```

---

## 第二步：在内网电脑上安装

### 1. 安装 Python 包

```bash
cd crawler

# 从本地目录安装所有依赖
pip install --no-index --find-links=./offline_packages -r requirements.txt
```

### 2. 安装浏览器

#### 方法 A：直接复制（推荐）

如果在外网已经下载好浏览器，直接复制到 Playwright 默认目录：

- Windows:
  ```cmd
  xcopy /E /I offline_browsers\chromium-1422 %USERPROFILE%\AppData\Local\ms-playwright\chromium-1422
  ```

- Linux/Mac:
  ```bash
  mkdir -p ~/.cache/ms-playwright
  cp -r offline_browsers/chromium-1422 ~/.cache/ms-playwright/
  ```

#### 方法 B：设置环境变量

也可以设置环境变量让 Playwright 使用本地浏览器：

```bash
# Windows (cmd)
set PLAYWRIGHT_BROWSERS_PATH=%CD%\offline_browsers
python analyze.py

# Windows (PowerShell)
$env:PLAYWRIGHT_BROWSERS_PATH="$(pwd)\offline_browsers"
python analyze.py

# Linux/Mac
export PLAYWRIGHT_BROWSERS_PATH=$(pwd)/offline_browsers
python analyze.py
```

## 快速测试

安装完成后，运行：

```bash
python analyze.py
```

看看能不能正常打开浏览器！

## 常见问题

### Q1: 浏览器版本不对怎么办？

**A**: 先在外网运行：
```bash
pip install playwright
playwright install chromium
```
然后查看 `%USERPROFILE%\AppData\Local\ms-playwright`（Windows）或 `~/.cache/ms-playwright`（Linux/Mac）下的目录名，把对应的文件夹复制到内网。

### Q2: 下载的 Python 包不全？

**A**: 确保在外网下载时网络正常，可以重复运行 `pip download`，它会自动跳过已下载的文件。

### Q3: 不想下载这么多包？

**A**: 可以使用我们提供的准备脚本（如果有），或者尝试：
```bash
pip wheel -r requirements.txt -w ./offline_packages
```

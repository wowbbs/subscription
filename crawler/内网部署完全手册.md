## 🚀 内网部署步骤（Windows 64位）

### 前提条件
- ✅ 内网电脑已安装 Python 3.8+（你说有 3.14）
- ✅ 内网电脑已安装 Google Chrome 浏览器

---

### 第一步：复制项目到内网电脑
将整个 `crawler/` 文件夹复制到内网电脑的任意位置。

---

### 第二步：安装 Python 依赖

1. **打开命令提示符（CMD）**
   - 按 `Win + R`，输入 `cmd`，回车

2. **进入项目目录**
   ```cmd
   cd D:\path\to\your\crawler
   ```
   （把上面的路径换成你实际复制到的路径）

3. **安装依赖（完全离线）**
   ```cmd
   pip install --no-index --find-links=./offline_packages -r requirements.txt
   ```

   如果 `pip` 命令不工作，试试：
   ```cmd
   python -m pip install --no-index --find-links=./offline_packages -r requirements.txt
   ```

   看到 `Successfully installed` 就说明安装成功了！

---

### 第三步：配置目标网址

1. **找到 `.env.example` 文件**
2. **复制一份，并重命名为 `.env`**
   - 右键 `.env.example` → 复制
   - 右键空白处 → 粘贴
   - 重命名粘贴后的文件为 `.env`（注意：Windows 默认隐藏扩展名，要确保真的改成 `.env`）

3. **编辑 `.env` 文件**
   - 右键 `.env` → 打开方式 → 选择记事本
   - 修改 `TARGET_URL` 为你的内网地址：
     ```
     TARGET_URL=https://qiankundg.web.guosen.com.cn/apps/opp/index.html?theme=web2
     ```
   - 保存并关闭

---

### 第四步：测试运行

1. **在命令提示符中输入**：
   ```cmd
   python analyze.py
   ```

2. **预期结果**：
   - 会自动打开一个 Chrome 浏览器窗口
   - 浏览器会访问你配置的目标网址
   - 如果配置正确，不会提示「非配套客户端」

## ⚠️ 如果 Chrome 浏览器找不到？

如果提示找不到 Chrome，请手动指定路径。

### 方法一：通过 `.env` 文件配置（推荐）

1. **找到你的 Chrome 安装路径**：
   
   **方法A：从快捷方式查找**
   - 右键 Chrome 快捷方式 → 属性
   - 在「目标」栏复制路径（去掉引号）
   
   **方法B：常见默认路径**
   - 64位系统（通常）：`C:\Program Files\Google\Chrome\Application\chrome.exe`
   - 32位系统：`C:\Program Files (x86)\Google\Chrome\Application\chrome.exe`
   - Edge 浏览器：`C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`

2. **编辑 `.env` 文件**，添加路径配置：
   ```ini
   # Chrome 路径配置
   CHROME_PATH=C:\Program Files\Google\Chrome\Application\chrome.exe
   ```

3. **重新运行**：
   ```cmd
   python analyze.py
   ```

### 方法二：通过代码直接指定

1. **打开 `config.py` 文件**，找到 `BrowserConfig` 类：
   ```python
   @dataclass
   class BrowserConfig:
       """浏览器配置"""
       headless: bool = False
       channel: str = 'chrome'
       executable_path: str = None  # 修改这里
   ```

2. **修改 `executable_path` 参数**：
   ```python
   @dataclass
   class BrowserConfig:
       """浏览器配置"""
       headless: bool = False
       channel: str = 'chrome'
       executable_path: str = r'C:\Program Files\Google\Chrome\Application\chrome.exe'
   ```

3. **保存文件并重新运行**：
   ```cmd
   python analyze.py
   ```

### 方法三：使用 Edge 浏览器替代

如果没有 Chrome，可以尝试使用系统 Edge：

1. **编辑 `.env` 文件**：
   ```ini
   BROWSER_CHANNEL=msedge
   CHROME_PATH=C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe
   ```

2. **重新运行**：
   ```cmd
   python analyze.py
   ```

## 💡 常见问题

### Q1: pip install 提示找不到文件？
**A:** 确保命令是在 `crawler/` 目录下运行的，并且 `offline_packages/` 文件夹确实存在。

### Q2: 提示 "找不到 Chrome"？
**A:** 在 `.env` 里添加 `CHROME_PATH`，指定你电脑上 Chrome 的完整路径。

## 🔍 关于 Playwright Chromium 浏览器的准备

你说内网已有 Playwright Chromium，请确认：

### 选项 A：从内网已有 Playwright 复制（最简单）

如果内网电脑已经用过 Playwright 并安装了浏览器，直接这样操作：

1. 在内网电脑上找到 Playwright 浏览器的安装位置：
   - Windows: `%LOCALAPPDATA%\ms-playwright\`
   - Linux/Mac: `~/.cache/ms-playwright/`

2. 找到 `chromium-1422`（或类似的文件夹）

3. 如果存在，直接跳转到「部署步骤」即可，浏览器无需重复安装

### 选项 B：从外网先装好浏览器再打包

1. 在外网电脑上安装 Playwright 并下载浏览器：
   ```bash
   pip install playwright
   playwright install chromium
   ```

2. 找到浏览器文件夹：
   - Windows: `%LOCALAPPDATA%\ms-playwright\chromium-<版本号>\`
   - Linux/Mac: `~/.cache/ms-playwright/chromium-<版本号>/`

3. 将整个 `chromium-<版本号>` 文件夹复制到 `crawler/offline_browsers/` 目录下

## 🚀 内网部署步骤（纯手动，零脚本依赖）

### 第一步：复制整个项目到内网电脑
确保上面的 `offline_packages/` 和程序文件都在内网电脑上。

### 第二步：安装 Python 依赖（在内网电脑）

打开命令行（cmd/PowerShell/终端），进入项目目录：
```bash
cd crawler
```

然后安装（注意使用 `--no-index`，完全不访问网络）：
```bash
pip install --no-index --find-links=./offline_packages -r requirements.txt
```

如果 `pip` 命令不工作，尝试：
```bash
python -m pip install --no-index --find-links=./offline_packages -r requirements.txt
```

### 第三步：浏览器的处理

#### 情况 1：内网已有 Playwright 浏览器
✅ 跳过此步！直接用已有的。

#### 情况 2：你已经从外网复制了 `offline_browsers/`
手动复制到 Playwright 的缓存目录：

**Windows:**
```cmd
mkdir %LOCALAPPDATA%\ms-playwright
xcopy /E /I offline_browsers\chromium-1422 %LOCALAPPDATA%\ms-playwright\chromium-1422
```

**Linux/Mac:**
```bash
mkdir -p ~/.cache/ms-playwright
cp -r offline_browsers/chromium-1422 ~/.cache/ms-playwright/
```

#### 情况 3：既没有现成的，也没准备 `offline_browsers/`
可以在代码里配置使用系统自带 Chrome 浏览器！

编辑 `config.py`，找到 `BROWSER_CONFIG`，改成：
```python
BROWSER_CONFIG = {
    'channel': 'chrome',  # 使用系统已安装的 Chrome/Edge
    'executable_path': None,  # 让 Playwright 自动找
}
```

或者手动指定 Chrome/Edge 路径：
```python
BROWSER_CONFIG = {
    'channel': 'chrome',  # 或者 'msedge'（Windows）
    'executable_path': r'C:\Program Files\Google\Chrome\Application\chrome.exe',  # 你的 Chrome 路径
}
```

### 第四步：配置环境变量
1. 复制 `env.example` 为 `.env`
2. 编辑 `.env`，设置 `TARGET_URL` 为你的内网地址

### 第五步：测试运行
```bash
python analyze.py
```

## 💡 常见问题

### Q1: pip install 提示找不到文件？
**A:** 确保你是在 `crawler/` 目录下运行的，并且 `offline_packages/` 确实存在。

### Q2: 提示找不到浏览器？
**A:** 方案一：直接用系统 Chrome/Edge（修改代码里的 browser.py 的浏览器配置）
方案二：先在内网手动运行 `playwright install chromium` 尝试（如果能暂时连网）

### Q3: 还是提示「非配套客户端」？
**A:** 别慌！把错误信息告诉我，我们继续调！
